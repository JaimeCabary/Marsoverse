## 🌟 Overview

**Marsoverse** is an immersive, browser-based 3D game universe that transports players to a colonized Mars. Built with Vanilla JavaScript, Three.js for 3D rendering, Solana for Web3 integration, and the Honeycomb protocol for decentralized player data.

Whether you're coding in the Zepta Terminal, exploring 3D Mars maps, or earning XP through missions, Marsoverse blends education, strategy, and adventure in an accessible metaverse experience.

## 📖 The Story

In Marsoverse, Earth's core has disintegrated, causing the planet to explode. Forward-thinking scientists channeled the explosive energy to warm Mars' cold surface, making it habitable for humanity's survivors. 

Now, as a Martian pioneer, your goal is to **explore, survive, and thrive** on this new world.

## ✨ Key Features

### 🌍 Immersive 3D Exploration
- **Powered by Three.js** with dynamic Mars terrain
- Orbit controls, asset loading (ships, bases)
- Dynamic lighting, shaders, and reflections
- 360-degree viewer for immersive experience

![Mars Viewer](MARS-WALKTHRU/mars.png)

### 💻 Zepta Terminal
- **UNIX-like command-line interface** for coding and control
- Commands: `/help`, `/date`, `/status`, and more
- Real consequences for every action
- Integrated chatbot for guidance

![Zepta Terminal](MARS-WALKTHRU/agaa.png)

### 🎮 Missions & Mini-Games
- Mars-themed games to earn **XP** and **SOL** tokens
- Daily login rewards
- Progress tracking with local storage
- Mission-based gameplay progression

### 🛰️ Real-Time Mars Data
- Pull weather data from **NASA APIs**
- Real Mars images and authentic experience
- Dynamic content updates

### 🔗 Web3 Integration
- **Solana wallet** connectivity
- **Honeycomb protocol** for on-chain data storage
- Player decisions, XP, and rewards tracked
- Mobile deep linking (in progress)

![Main HUD](MARS-WALKTHRU/marzo.png)

## 🎯 How to Play

```mermaid
graph LR
    A[Landing Page] --> B[Onboarding]
    B --> C[Connect Wallet]
    C --> D[Main HUD]
    D --> E[Accept Mission]
    D --> F[Zepta Terminal]
    D --> G[Explore Mars]
    D --> H[Mini-Games]
    E --> F
    F --> I[Earn XP & Rewards]
    H --> I
```

1. **🚪 Landing & Onboarding** - Enter your name, age, and connect your Solana wallet
2. **🎯 Accept a Mission** - Choose from available missions on the HUD
3. **⌨️ Use Zepta Terminal** - Execute commands, code solutions, earn XP
4. **🌎 Explore Mars** - Navigate the 3D viewer with NASA weather data
5. **🎲 Play Mini-Games** - Earn rewards and build your Martian empire
6. **📅 Daily Login** - Return daily for bonus rewards

## 🚀 Getting Started

### Play Now (No Installation!)
Simply visit: **[marsoverse.netlify.app](https://marsoverse.netlify.app)**

### Development Setup

```bash
# Clone the repository
git clone https://github.com/JaimeCabary/Marsoverse.git

# Navigate to directory
cd Marsoverse

# Install dependencies
npm install --legacy-peer-deps

# Start local server
node server.js
# or use Live Server extension
```

### 📁 Key Pages
- `index.html` - Landing page with onboarding
- `marzo.html` - Main game HUD and navigation
- `zeep.html` - Zepta Terminal interface
- `mars-viewer/dist/index.html` - 3D Mars exploration
- `admin.html` - Admin panel (password-protected)
